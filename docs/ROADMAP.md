# Product Roadmap

## V0.2 — Dedicated foundation
Dedicated UI/package, localization, import detector, protocol registry, CI.

## V0.3 — First real engines
OpenVPN + VLESS/Reality/VMess connection gates, lifecycle tests, DNS/routing tests, QR import.

## V0.4 — Public subscriptions
Subscription parsing, profile groups, latency test, favorites, routing and backup/export.

## V0.5 — PVNetwork cloud
Authentication, dynamic catalog, services, renew/add traffic, server pools and smart selection.

## V0.6 — More engines
WireGuard, Trojan/Shadowsocks, Hysteria2/TUIC/AnyTLS as licensing and platform tests permit.

## V0.7 — Enterprise
OpenConnect families and IPsec platform integration.

## V1.0 — Public release
Production signing, privacy/data-safety documents, crash/telemetry policy, Play AAB, reproducible release gates and full protocol compatibility matrix.
