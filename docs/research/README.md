# PVNetwork research gate

No production networking feature may be advertised before it is implemented and tested in PVNetwork.

Required order for the current milestone:
1. Protocol inventory.
2. Mature reference-client inventory.
3. UI, navigation, import, profile and connection-lifecycle review.
4. Core/license review.
5. PVNetwork UX and core-selection decisions.
6. Implementation, build, integration tests and E2E verification.

Reference projects are studied for engineering lessons only. PVNetwork must not copy third-party branding, proprietary assets, or code whose license is incompatible with PVNetwork's distribution model.
